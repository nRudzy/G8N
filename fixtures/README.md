# G8N fixtures

All fixtures in this directory are synthetic and safe for the public repository. They do not contain real Notion content, real company exports, candidate data, credentials, tokens or private payloads.

Datasets:

- `smoke`: small deterministic offline data for basic local checks.
- `edge`: incomplete, duplicate, republished, ambiguous and quota cases.
- `performance`: template only; generate large batches locally and do not commit them.

The payloads are intentionally shaped like the expected providers, but exact compatibility must be reviewed after API access and examples are validated in G8N-003.
